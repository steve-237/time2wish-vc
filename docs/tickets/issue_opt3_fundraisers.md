## Description
Introduce the Birthday Fundraisers & Group Gift Crowdfunding module into Flutter mobile, allowing friends and family to pool money for collective birthday presents with real-time goal tracking.

## Scope & Acceptance Criteria
- [ ] Inspect and connect backend `/api/fundraisers` REST endpoints
- [ ] Implement `FundraiserService` in `mobile_flutter/lib/core/services/fundraiser_service.dart` with offline cache
- [ ] Implement Fundraiser card and contribution dialog in Flutter mobile
- [ ] Dynamic progress bar calculation (amount collected vs target goal)
- [ ] Add unit tests in `mobile_flutter/test/fundraiser_service_test.dart`
